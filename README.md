# MyApp (Android)

This repository is an Android Studio–compatible Gradle project.

## Build

From the repo root:

```bash
./gradlew assembleDebug
```

The resulting APK will be under:

```
app/build/outputs/apk/debug/
```

## Structure

- `app/` - Android application module (Jetpack Compose)
- `archived/web-nextjs/` - archived Next.js scaffold (kept for reference)
